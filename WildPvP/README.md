# WildPvP companion tools

The WildPvP page in WildSpark is a single control hub for these separately packaged Forever tools:

- **Spy 1.3.8-Forever19** — nearby enemy alerts and player lists. Originally created by Immolation; updated and ported for Forever by Slipjack. The owner supplied permission to use this package in WildSpark. Its source README and credits are retained.
- **Capping 12.1.7** — classic battleground timers. Author: Funkeh. Both addon folders and the original `X-License` notice are retained unchanged.
- **Highground Battlegrounds 0.8.1** — battleground panels, objective timers, map intel, and callouts. Author: kemicofa. The original MIT license, README, and bundled asset notices are retained.

Install all four ZIP folders (`WildSpark`, `Spy`, `Capping`, `Capping_Options`, and `HighgroundBattlegrounds`) into the client's `Interface/AddOns` directory. Use **WildPvP** in WildSpark to manage component enablement and open each tool. Enabling or disabling a component requires `/reload` before it takes effect.

The supplied BattleGroundEnemiesFixed archive is intentionally not part of this bundle. It contains an `AGENTS.md` that forbids using that addon's source or implementation as a basis for another project.
