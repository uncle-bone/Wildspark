# Archived WildPvP sources

The WildPvP module source, the supplied component sources, the WildSpark integration shim, author notices, and build scripts are preserved here for possible future restoration. None of them is loaded or included in the active WildSpark addon package starting with 2.2.49.

The source package folders are retained under `Packages/`. The integration shim is under `Modules/`, and the scripts formerly used by the release workflow are under `Scripts/`.

This archive is repository source only; it is not a separately installable addon or a current release.
