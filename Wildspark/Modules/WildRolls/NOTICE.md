# WildRolls attribution

WildRolls incorporates and adapts ForeverLootRollMover 1.3.4 by Stilo, supplied
by the WildSpark maintainer and included with the author's permission.

The integrated code retains the upstream module's Edit Mode previews, native
group-loot positioning, loot-received alert positioning, vote counts, gamepad
support, scale/spacing/stack controls, and guarded Alt-drag behavior. WildSpark
connects these features to its own saved settings and menu, uses `/wildrolls`
commands, and identifies the module as WildRolls.

The original author retains ownership of the upstream work. ForeverLootRollMover
1.3.4 identifies itself as a test build; WildSpark's source and package checks
do not replace testing in the WoW Forever client.
